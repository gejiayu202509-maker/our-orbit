# OUR ORBIT｜我们的轨道

葛家羽与牛一铭共同维护的私人数字恋爱博物馆。

## 预览

直接打开 `index.html`，或在目录内启动任意静态文件服务器。

## GitHub Pages

1. 将本目录推送到 GitHub 仓库。
2. 在仓库 Settings → Pages 中选择 `Deploy from a branch`。
3. 选择 `main` 分支和根目录 `/`。

项目不需要 npm、构建工具或后端服务。

## 页面

- `index.html`：双星序章首页。
- `universe.html`：银河导航与数字恋爱博物馆详情面板。

恋爱天数由 `js/site.js` 根据 2024-10-30 动态计算。
